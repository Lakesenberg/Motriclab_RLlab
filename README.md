## 题目细节

- 第 3 讲第 5 题原题写“环境类”，课稿实际将 `@envcfg("cartpole")` 用于配置类 `CartpoleCfg`；本题仍选 A。
- 第 3 讲第 7 题按该讲课稿的 `(obs, reward, done, info)` 选 B。第 4 讲的代码示例另行区分 `terminated` 与 `truncated`，实际编程应核对接口。
- 第 4 讲第 7 题按课稿表述选 A；两个速度项在数学上合并为 `-speed`，实际会鼓励降低速度。
